# 🍔 XB Food

XB Food is a modern and responsive food ordering web application designed to provide a seamless and user-friendly experience for browsing meals and restaurant menus.

---

## 🚀 Overview

XB Food is a front-end project that simulates a real-world online food ordering platform.  
It focuses on clean UI design, responsive layouts, and well-structured code organization.

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- JSON  

---

## ✨ Features

- Fully responsive design (Mobile & Desktop)  
- Clean and modern user interface  
- Dynamic content rendering using JSON  
- Organized file structure  
- Smooth navigation experience
